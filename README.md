# NOIR COFFEE

Адаптивный сайт кофейни NOIR COFFEE, созданный как учебный проект для практики HTML, CSS и JavaScript.

## Технологии:

- HTML5

- CSS3

- JavaScript

- Git / GitHub

- GitHub Pages

## Что реализовано:

- адаптивная вёрстка под разные размеры экрана;

- фиксированная навигация;

- плавная прокрутка;

- интерактивная навигация по категориям меню;

- hover-эффекты;

- favicon;

- публикация сайта через GitHub Pages.

# Цель проекта:

Практика вёрстки, адаптивного дизайна и JavaScript на основе макета кофейни.
